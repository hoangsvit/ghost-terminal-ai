# Support

This is a community-maintained experiment, not a managed incident-response service. Support is best-effort.

## Before asking a question

1. Read the [README](README.md), [Compute Engine setup guide](DEPLOY_COMPUTE_ENGINE.md), and [contribution guide](CONTRIBUTING.md).
2. Search [existing issues](https://github.com/hoangsvit/ghost-terminal-ai/issues) and use the on-page synthetic test scenarios.
3. Run the local checks from CONTRIBUTING.md and try `GET /api/health`.
4. Distinguish **Instant Scan** (offline heuristics) from **Analyze/Compare/Story** (require Ollama and Gemma).

## Where to ask

- **Unexpected app behavior:** [Bug report](https://github.com/hoangsvit/ghost-terminal-ai/issues/new/choose).
- **Feature proposal:** the Feature request issue form.
- **Setup or use questions:** the Question issue form.
- **Documentation correction:** the Documentation issue form.
- **Security concern:** [SECURITY.md](SECURITY.md); never post exploit details or sensitive input publicly.
- **Contributor behavior concern:** [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Include your OS/Python version, deployment type (local or VM), expected and actual behavior, reproducible steps, relevant *sanitized* synthetic output, and any non-sensitive error messages. Responses and fixes are not guaranteed.

The public Qwiklabs/Compute Engine demonstration is temporary and should not be used for real incident data.
