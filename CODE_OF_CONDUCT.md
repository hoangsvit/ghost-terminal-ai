# Code of Conduct

## Our commitment

Ghost Terminal AI aims to be a respectful, welcoming open-source project for people of different backgrounds and experience levels. Help others learn; critique code and ideas without attacking people.

## Expected behavior

- Be considerate, professional, and constructive.
- Assume good faith, ask clarifying questions, and credit others' work.
- Respect differences in experience, identity, language, and communication style.
- Give actionable review feedback focused on observable behavior.
- Respect contributors' privacy; do not publish personal information or private log data.

## Unacceptable behavior

Harassment, threats, hate speech, discriminatory remarks, unwanted sexual attention, deliberate intimidation, personal attacks, doxxing, spam, and repeated disruptive behavior are not tolerated. Retaliation for good-faith reports is prohibited.

## Scope

This policy applies to repository issues, pull requests, reviews, discussions and other project spaces, and when representing the project publicly.

## Reporting and enforcement

For ordinary community issues, use GitHub's **Report content** controls when available or contact the repository owner via a private channel that you already share. Do not publish identifying details in a public issue. If no private route is available, use GitHub's platform abuse-reporting options.

Maintainers will review reports as privately as practical, consider impact and context, and may issue warnings, remove content, restrict interaction or block contributors. Reports will be shared only with those necessary to handle them, subject to GitHub's platform controls. There is no promise of an immediate response.

For **security vulnerabilities**, use the separate [Security Policy](SECURITY.md), not a public Code of Conduct report.

This is a project-specific policy. It may be improved through an issue or pull request that does not disclose private incident details.
