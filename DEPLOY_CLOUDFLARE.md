# ☁️ Deploy Ghost Terminal AI on Cloudflare Workers AI

This is an **optional hosted mode**. It does not change the original Python + Ollama + Gemma 3 local demo. It reuses the existing responsive frontend and exposes the same JSON API contract via a Cloudflare Worker.

| Mode | Inference engine | Privacy | Access |
| --- | --- | --- | --- |
| Local | Gemma 3 via Ollama | Runs on the same computer | localhost |
| Hosted | Gemma 4 26B A4B via Cloudflare Workers AI | Sends pasted log to Cloudflare | Public HTTPS URL |

**Hacktoberfest Week 4**: this cloud branch uses a different open-weight model. The model is the main story generator, not a fake text template. A real inference still must be performed and captured before claiming a working demo.

## Prerequisites

- A Cloudflare account with Workers AI available: https://dash.cloudflare.com/
- Node.js 20+ and npm
- Access to this repository's files (clone or download the PR branch)
- Free Workers AI usage (currently 10,000 Neurons/day; see the pricing link below)

## Deploy manually (recommended to avoid storing Cloudflare API tokens in GitHub)

From the repository root:

```bash
git checkout feature/cloudflare-workers-ai-demo
npx wrangler@latest login
npx wrangler@latest deploy
```

Open the `https://ghost-terminal-ai-demo.<your-subdomain>.workers.dev` URL **actually printed by Wrangler**. Do not assume a URL until the deployment command succeeds. If the name is taken, change `name` in `wrangler.jsonc` to a unique Worker name.

A public test session:
1. Verify the model indicator shows `HOSTED GEMMA 4 READY` (this checks the binding, not remaining quota).
2. Click **Load sample log**.
3. Select **Haunting** and click **Awaken the terminal**.
4. Confirm the story and source echoes are generated by the hosted model.
5. Record a short screen capture and insert its share URL in the [DEV.to draft](DEVTO_SUBMISSION.md).
6. Verify the demo from a different browser/device.

## Cloudflare UI setup

No API key or token needs to be put in this repository. Wrangler's interactive login authorizes deployment into your Cloudflare account. The `AI` binding and both rate-limit bindings are configured automatically through `wrangler.jsonc`.

To add a custom domain, use the Worker settings / Routes & Domains in Cloudflare after the first successful deployment. The default `workers.dev` URL is enough for a challenge demo.

## Safeguards and limitations

- Hosted mode never executes the pasted input; it treats it as **untrusted data**.
- Input is validated and best-effort redacted, but **no secret detector is perfect**.
- The Worker does not intentionally persist input, add analytics, or expose API keys. Cloudflare may process request data under its own service policies.
- Input max 6,000 characters or 100 lines; generation output capped at 700 tokens.
- Per-IP rate limiter: approximately 3 generations / minute.
- Per-location site-wide limiter: approximately 12 generations / minute.
- Cloudflare rate limits are **not globally strict** and can treat shared-IP users alike; public quota exhaustion is still possible.
- Cloudflare Workers AI can reject requests because of capacity or daily Free quota. The UI will show an error; it is not a fake story generator.
- Do not label the hosted page as “100% local”. Its on-screen notices are rewritten explicitly to describe Cloudflare processing.
- The hosted model can ignore JSON instructions sometimes; the fallback displays actual model text, never a canned fake story.

## Offline tests

```bash
node --test cloudflare/worker.test.mjs
node --check cloudflare/worker.mjs
python -m unittest discover -s tests -v
```

The Node tests use a **mock Workers AI binding**. They verify request validation and response structure; they do not prove that a deployment ran Gemma. Record real inference separately.

## Cost control

Cloudflare Workers AI currently includes **10,000 free Neurons/day**. On Workers Free, calls fail after the allocation is consumed. Limits reset at **00:00 UTC**. Workers Paid allows overages billed separately. See [official pricing](https://developers.cloudflare.com/workers-ai/platform/pricing/).
