# Hacktoberfest 2026 Week 4 submission checklist

The repository was created publicly during the Week 4 window. **Publishing code alone does not submit a contest entry.**

## 1. Run a real open-weight model

- Install https://ollama.com/download and Python 3.10 or newer.
- Download the model: `ollama pull gemma3:1b`.
- From this repo run `python app.py` (or `py app.py` on Windows).
- Open http://127.0.0.1:8765 and confirm **LOCAL MODEL READY**.
- Click **Load sample log** -> **Awaken the terminal**.
- Record a screen capture showing the resulting generated story and the local model ready. UI screenshots without model inference are not proof of a working AI demo.

## 2. Submit to DEV

- Open https://dev.to/challenges/hacktoberfest-week4-2026-10-26
- Confirm that the official submission interface still accepts entries. The written deadline is 31 October 2026 at 23:59 PDT (1 November 2026 at 13:59 Vietnam time).
- Use the challenge's official **Submission Template**.
- Copy/adapt the draft in [DEVTO_SUBMISSION.md](DEVTO_SUBMISSION.md).
- Add a link to the actual video and the verified repo URL.
- Keep the tags `devchallenge` and `hf26challenge`.
- Publish and double-check the public post link.

## 3. Check Hacktoberfest rewards

After organizers review a valid submission, check https://hacktoberfest.com/my/ for your Sticker Book. Writing source code or creating a repo does not automatically award a sticker.

Rules: https://dev.to/page/hacktoberfest-week4-2026-10-26-contest-rules
